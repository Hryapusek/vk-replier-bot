# Coder
## Description
The main goal of this project is to provide a simple coder for files in format
```
Name Surname; 2542
...
```

It converts data into something like this:
```
789238957345; 2542
...
```

New list does not really make any sense, and only the one who knows his number can obtain his data. For example if Name Surname enter his number, then he can get the data.
